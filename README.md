# Polyglot Voice – Android APK (offline)

Download on the phone and install:
https://github.com/moocky/test-repo/raw/apk-download/PolyglotVoice-offline-arm64.apk

- Runs fully on the phone (no server, no account). Offline speech recognition needs Android 13+.
- 64-bit Android (arm64). Signed with a debug key: for sideloading, not for Google Play.
- Built from branch `claude/multilingual-speech-translation-app-fuang1` at commit 00c6f7c.
